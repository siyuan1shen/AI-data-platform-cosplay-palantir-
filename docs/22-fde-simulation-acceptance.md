# FDE 多公司模拟验收报告

验收日期：2026-08-30

## 1. 验收目标

以真实 FDE 的交付顺序验证本地平台，而不是只验证孤立接口：管理问题定义、多人调研、企业对象建模、业务数据接入、分析与因果假设、管理决策、行动执行、结果测量、Agent 人工审批和学习资产沉淀。

用户提供的三份调研总结和一份问卷答案导出只用于校准调研语境、问题粒度和管理视角；原文件内容没有复制到仓库，也没有写入验收数据库。所有自动化和浏览器验收记录均为程序内生成的虚拟数据。

## 2. 虚拟组合

| 虚拟企业 | 行业 | 项目一 | 项目二 | 主要视角 |
|---|---|---|---|---|
| 华南智造样本公司 | 消费电子 ODM/OEM | 新品市场验证 | 订单交付改善 | 总经理、产品、市场 |
| 恒川精密样本公司 | 精密零部件制造 | 供应商质量提升 | 产能交期协同 | 总经理、质量、采购 |
| 云桥软件样本公司 | B2B SaaS | 客户续约增长 | 产品交付提速 | CEO、客户成功、产品 |

共验证 3 家公司、6 个独立项目、18 组角色—项目组合。每个项目都包含章程、高优管理问题、调研预览与确认、对象类型、同名外部标识和业务数据确认；主案例继续贯通完整决策学习闭环。

## 3. 已通过的业务链路

1. 公司选择和项目选择相互独立，同一公司可拥有多个项目。
2. 草稿项目必须先完成章程和高优管理问题，才能进入调研。
3. 问卷答案 CSV 可预览、跳过空答案、合并同一视角的重复回答，再人工确认。
4. 检查维度、问题类型和访谈视角在预览、持久化、页面展示和导出中保持一致；不同角色不会被错误合并。
5. 同一个外部标识可分别存在于不同项目，不会跨公司或跨项目复用对象。
6. 统一映射可以从一份虚拟 ERP CSV 建立客户、订单、关系、事件和指标，并保留对象来源血缘及变更集审计。
7. 分析发现、可证伪因果假设、决策选项、决策、行动计划、行动执行和 Outcome 可以顺序推进。
8. Outcome 会生成持久化学习事件；经处理、批准和执行后形成项目学习资产。
9. Agent 创建对象的命令在批准前不会写入；批准后只执行一次；拒绝命令不会产生对象。
10. 独立浏览器实例完成了公司创建、项目创建、章程、阶段门禁、CSV 文件选择、预览、确认、刷新持久化、答案导出请求以及调研到建模的推进。

## 4. 验收中发现并修复的问题

- 调研导入原先丢失检查维度、问题类型和受访角色，导致多个管理视角混在同一个答案中。现已增加兼容字段和数据库迁移，旧 CSV 无角色列时仍可导入。
- V2 事务原先可能在 HTTP 响应发出后才提交。前端创建公司后立即查询项目时，偶发看不到刚创建的公司并显示 404。现改为响应发送前完成事务提交。
- `start.ps1` 支持自定义 `DataRoot`，但 `stop.ps1` 原先无法使用同一路径停止实例。现已补齐对应参数。

## 5. 工程验证结果

- `pytest`：269 项通过；
- 新增 FDE 场景测试：通过；
- Ruff：通过；
- V2 前端 JavaScript 语法：通过；
- V2 Alembic：可从空数据库依次升级到 `v2_0003_research_perspectives`；
- 真实浏览器控制台：无错误或警告；
- 隔离测试实例已停止，合成数据库和临时上传文件已删除。

## 6. 尚未声称完成的能力

- 当前持久化血缘的直接查询重点是“来源行 → 对象”；关系、事件和指标有变更集审计，但还没有统一的通用血缘图查询接口。
- CRM/ERP 验收使用声明式 CSV 映射，不代表 SAP、用友、金蝶、MES 等正式连接器已经完成。
- Agent 具备上下文读取、提案、人工审批和受控执行，尚不是可自主规划长任务的生产级多 Agent 系统。
- strict `mypy` 仍报告 108 条历史类型债务，集中在 learning、integration、change 和服务层类型收窄；运行测试通过不等于这项工程债务已经清零。
- 当前结论是“本地 FDE 核心演示闭环可用”，不是“已经达到大型企业生产部署标准”。

## 7. 可重复执行

核心业务场景位于 `tests/test_fde_multicompany_scenario.py`。在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_fde_multicompany_scenario.py -q
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check --no-cache .
node --check src\enterprise_insight\web\static_developer\app.js
node --check src\enterprise_insight\web\static_executive\app.js
```
