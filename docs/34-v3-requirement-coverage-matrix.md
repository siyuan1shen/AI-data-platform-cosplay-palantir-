## 不能用本地结果替代的证据

MOCK 只能证明程序状态机、持久化和评分链路；它不能证明外部模型的准确性。SQLite/REST 适配器测试不能替代真实 PostgreSQL 或具体 ERP/MES/CRM 厂商验收。合成企业流程不能证明真实企业已经产生经营收益。因此这些项保持“部分验证”，不以页面数量或测试总数宣称全部完成。

## 复验命令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-v3.ps1 -RequireRuntime
```

真实 PostgreSQL 验收前，必须只对一次性测试库设置 `EI_TEST_POSTGRES_DSN`；真实模型验收前，必须使用合成材料并明确允许外发和调用预算。
