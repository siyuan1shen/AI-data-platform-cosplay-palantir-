# V3 当前产品实现状态

更新时间：2026-09-10。

本文描述当前 V3 代码真正可运行的范围；13—30 号文档是产品设计、工程规范和实施清单，不应根据文档存在把未验收项误读为已经实现。

## 已完成的本地核心闭环

- 公司与项目分离选择，项目上下文贯穿所有模块；
- 项目初始简报与正式管理诊断分离；正式诊断接口只在投影进入分析阶段后开放；
- 通用问卷答案 CSV 的读取、预览、确认、去空和分视角合并；
- 企业投影 Agent、管理决策 Agent 两个主入口；企业投影 Agent 能读取项目上下文、设计投影和调研答案，调用受控工具提出节点/关系提案，支持独立对话、附件文本提取、历史删除和阶段交接；在离线验收模式下，材料命中订单履约场景时可生成 21 个对象/22 条关系的可审核变更并经动作中心审批执行；
- 企业设计投影层：组织、岗位、能力、流程、信息资产、资金池、系统和指标定义等节点，职责/顺序/信息流/资金流等实体关系，均有独立版本历史，不与 ERP 运行对象混表；
- 岗位与流程工作设计：岗位职责的预期结果、设计理由、决策权和协同要求；流程步骤的可衡量性、指标候选、定性信号、指标博弈与代理风险，可由企业投影 Agent 提案并人工审批；
- 默认离线响应，以及逐次显式授权的 OpenAI、DeepSeek、OpenAI-compatible、Mock 模型调用；
- 模型配置的本地加密保存、连接测试、更新与删除；
- 对象类型、对象、实体关系边、图路径、事件、指标和来源血缘；
- 投影就绪度检查，分别展示设计层是否可用与运行层是否达到发布门禁；
- 上游设计基线与可选下游运行投影：所有企业先发布设计基线，有系统数据的企业再创建绑定到指定基线的运行投影；正式开发者导入会阻止未绑定运行投影的下游数据；
- 文件连接器、SQLite/PostgreSQL/REST 只读连接器、字段预览、只读字段映射候选、声明式映射、ChangeSet 和身份桥接；
- 系统关系映射：可把来源表外键明确映射为本体关系的两端角色；批准后物化为 `SYSTEM_BOUND` 关系，目标不存在或不唯一时只记录可追溯警告，不猜测、不静默连边，关系证据回指原始材料片段；
- 发现、因果假设与边、决策选项、决策、行动计划和 Outcome；
- 结构化 Agent 提案的创建、批准、拒绝及受控执行；
- 学习事件、学习提案和带适用边界的资产沉淀；
- 不可变管理报告和企业投影发布快照，发布内容包含设计层与运行层、来源清单、摘要、预览与下载；
- V3 单头 Alembic 迁移、本地实例隔离、桌面/脚本启动和诊断工具；旧 V1 API、界面和迁移链已关闭。
- 开发端只有一套权威的高级工具入口，旧未路由发布页保留为兼容出口；关系图组件按需加载，首屏不再提前加载图布局依赖。
- 本地合成性能基准已覆盖 1 万/3 万和 2 万/6 万对象/关系规模的局部图及筛选查询；两档均满足 500ms 查询门槛，但尚未替代生产规模验收。

## 正确的产品定位

当前版本不是 ERP，也不是已经完成的 Foundry 替代品。它是一个可本地落地的“管理层企业决策投影台”：用问卷、访谈和文件数据建立第一版企业数字投影，让 Agent 在明确模块内协助建模、分析、交接和提案，再由人把正式变更写入可追溯的对象—关系—因果—决策—行动闭环。

下一阶段应由真实客户项目拉动：先选择一个高价值管理问题，再补对应系统连接器、指标和验证闭环，而不是横向堆叠空功能。
