# 设计文档索引

当前 V3 操作以 [31 使用手册](31-v3-user-manual.md)为准；实现及验收状态见 [32 验收记录](32-v3-verification-report.md)。完整开发范围由 [29 改进方案](29-v3-complete-improvement-plan.md)和 [30 实施任务清单](30-v3-improvement-backlog.md)确定。以下早期文档保留历史背景，不作为完成声明。

本文档集是项目建设的唯一规划入口。产品首先服务核心管理层：从问卷、访谈和现场调研形成企业的初始数字投影，再逐步接入业务系统，以对象、关系、事件、指标、因果、决策、行动和结果持续完善企业在数字世界中的投影。

## 当前取舍

- 集中建设管理层调研、企业本体、关系图、数据接入、因果决策、行动学习、Agent 工具和相似企业指导。
- 安全治理、复杂多租户、加密交换、云端高可用、扩展沙箱和微服务不作为当前产品模块或交付目标。
- 现有登录、凭据和本地数据边界只作为维持程序可运行的基础设施，不继续扩展，也不在当前阶段拆除。
- 所有新功能必须同时完成领域模型、数据库、API、前端、示例数据、测试和端到端演示；只有后端接口不算完成。
- 当前仓库只保留 V3 运行代码、迁移、启动链和必要契约；旧根目录 V1/V2 运行代码已删除，避免出现双运行路径。
- 后续编码以真实项目缺口和 21 号文档的未完成项为输入；任何“已完成”结论以 23 号现状文档和可运行测试为准。
- 24 号文档优先约束业务流程顺序；13–21 号文档中与“先填写正式管理问题”冲突的早期阶段描述，按 24 号文档解释。
