# V3 当前能力清单

更新：2026-09-10。本清单只描述当前代码已提供的能力与验证边界，不能把设计文档中的未来能力当成现成功能。

## 可以直接使用

| 能力 | 建设端 | 使用端 | 当前证据边界 |
| --- | --- | --- | --- |
| 公司与项目 | 创建、切换、独立修订 | 选择已发布项目 | 本地多公司、多项目隔离已验收 |
| 无系统企业建模 | 导入 CompanyCheck/CSV/TXT/DOCX/PDF/XLSX/JSON，预览确认，企业投影 Agent 提案 | 查看已发布企业投影 | MOCK 流程与合成数据已验收；真实模型质量待验证 |
| 设计投影 | 对象、关系、岗位、流程、职责、信息流/资金流的增删改查和证据回指 | 图、对象详情、发布快照 | 图查询和关系角色校验已验收 |
| Agent 动作 | 预演、审批、执行、日志、继续、观察和回滚 | 不直接暴露开发动作 | 动作必须通过结构化工具；并发执行使用数据库条件更新，Worker 使用租约围栏和终态落库保护 |
| 管理决策 | 管理 Agent、设计/结果信号、问题、假设、方案、决策、行动、结果反馈 | 管理层查询和反馈 | 合成链路已验收；真实管理收益待试点 |
| 系统接入 | FILE、SQLite、参考 PostgreSQL/REST 只读连接器；字段/关系映射、原始批次、重算和血缘 | 查看统一语义数据与导出 | 具体 ERP/MES/CRM 厂商尚未逐一适配；MYSQL/SQLSERVER 会在登记阶段明确拒绝，不会伪装成可用连接器 |
| 发布与交换 | 发布不可变投影、JSON/CSV/XLSX/离线 ZIP 导出与恢复预览 | 查看正式发布版本 | PostgreSQL/Docker/生产规模尚未本机闭环 |
| 评测与学习 | 持久化评测集、Worker、动作/引用评分、学习案例和跨企业参考 | 查看 Agent 输出与管理反馈 | 本地 MOCK 机制已验收，真实模型轨迹待授权 |

## 明确不应误称为已完成

- 本项目不是 ERP、MES、CRM，也不会自动替代这些系统。
- 通用连接器不等于某个具体厂商的现成插件；厂商字段、权限、分页、限流和业务口径必须单独验收。
- MOCK、本地 HTTP 回放和合成企业只证明程序边界、状态机和可回放流程，不证明模型判断准确或企业经营已经改善。
- 尚未在本机完成真实 PostgreSQL、Docker/干净机器、生产规模导入导出/浏览器性能、真实外部模型和企业试点。
- OCR、向量/混合检索、流式计算、分布式对象存储、总部自动汇聚和自动因果实验不属于当前本地单体交付。

## 推荐的最短使用顺序

1. 建设端创建公司和项目。
2. 导入问卷/访谈材料并确认预览。
3. 使用企业投影 Agent 生成草稿，人工审核并执行动作。
4. 在投影图和对象详情中微调，再发布设计基线。
5. 有系统数据时登记只读来源，先预览字段和关系，再逐条审核映射并同步。
6. 使用端由管理层查询发布版本，要求管理 Agent 分析信号，确认问题并记录决策、行动和实际结果。
